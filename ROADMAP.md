# Roadmap: Yankuilotl+ Hackathon (36h)

## Fase 1: Cimiento y Datos (Horas 1-8)
- [ ] Configuración de entorno (Vite + FastAPI).
- [ ] Definición de estructura JSON para Estaciones (Hubs) y Segmentos de Calle.
- [ ] Setup de Mapbox con coordenadas reales de estaciones RUTA (11 Sur, Vía Atlixcáyotl).

## Fase 2: Lógica de Movilidad (Horas 9-20)
- [ ] Implementación de algoritmo de "Ruta más Sana" en Python con NetworkX.
- [ ] Endpoint de "Validación de Bache" (Lógica de 3 votos).
- [ ] Desarrollo de la lógica de "Saldo Híbrido" (Tarjeta RUTA + Banco).

## Fase 3: Experiencia de Usuario e Interfaz (Horas 21-30)
- [ ] UI de Mapa con filtros de "Hubs de Energía" y "Zonas de Recompensa".
- [ ] Implementación del "Modo Legado" para Adultos Mayores.
- [ ] Simulación de NFC Tap-to-Pay en el frontend.

## Fase 4: Pulido y Pitch (Horas 31-36)
- [ ] Integración final Front-Back.
- [ ] Preparación de Demo: "El camino de una batería desde 10% hasta el Hub".
- [ ] Exportación de presentación de Canva con métricas de ahorro de OpEx.
